# Entity Naming Review — Specific Checks

Targeted review criteria for each entity kind. Run through these when adding or auditing entity names. The general method is `naming-craft.md`; the culture patterns and worked examples for a particular setting are in that world's `guidance/naming-conventions.md`.

## Location Names

Locations are named by the people who live there or found them. Ask:
- **Who found this place?** A state surveyor names differently than a salvage crew.
- **When?** Names coined during a scramble should feel improvised and functional. Names coined by a settled authority might be more deliberate.
- **Has the name changed?** Many locations have an official name and a name everyone actually uses. Include both where relevant.
- **Is it named after someone?** Real places often are. A person's name beats a description of the place's function.

Common fails:
- Every location named for its defining feature
- No mundane location names (every location sounds significant)
- All locations using the same naming register

## Event Names

Events are named after the fact, usually by historians or by popular usage. Ask:
- **What did people call it while it was happening?** Often different from the historical name.
- **Who named it?** Academics name events differently than survivors.
- **Is the name earned?** A good earned name is evocative, specific, sticky. Not every event needs one — some can just be "the 2345 corridor dispute."

Common fails:
- Every event capitalized and formalized
- All events named using the same "The [Noun] [Noun]" pattern
- No events referred to by their date or location instead of a coined name

## Faction Names

Factions name themselves, or get named by others. Ask:
- **Did they choose this name?** Self-chosen names signal aspiration. Names given by others signal reputation.
- **Does it sound like something a committee would produce?** Some factions ARE committees and should sound like it. Others should sound like what people actually call them.
- **Is there a short form?** Anything people say often gets shortened. Record what it shortens to.

Common fails:
- Every faction name follows [Adjective/Place] [Role] [Organization Type]
- No factions with names that don't explain their function
- All factions sound equally formal

## Artifact Names

Artifacts are named by their makers, their users, or legend. Ask:
- **Is this a technical designation or a popular name?** Both can exist for the same object, and the gap between them is usually interesting.
- **Does the name tell you too much?** An artifact named for exactly what it does is a spec sheet. One named for what it sounded like is a mystery.
- **Is it named after its effect, its maker, or something unrelated?** Mix these.

Common fails:
- Every artifact name describes its function
- No artifacts with names that have been corrupted, shortened, or misattributed over time

## People Names

See `naming-craft.md` for the method and the world's `guidance/naming-conventions.md` for its culture patterns. Additional checks:
- **Does the name match the character's culture and species?** Cross-check against the world's conventions.
- **If they code-switch, is that reflected?** Someone with a professional name in one culture's register and a personal name in another should have both referenced.
- **Are there nicknames or shortened forms?** Real people have these, and which one a speaker uses says who they are to each other.
